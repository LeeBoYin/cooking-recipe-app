## 一、設計原則

1. **溫暖家常**：像在朋友家的廚房。米白紙感的底、白色卡片、燈泡黃的重點、手繪的小圖示。
2. **安靜的版面**：卡片和按鈕不用邊框、不用陰影；分頁沒有標題列；首頁不用區塊標題，靠顏色與距離分出區塊。
3. **只有大廚會跳出來**：粗黃邊只用在「和大廚聊聊」。其他地方用淡色與留白，不搶大廚的位置。
4. **使用者的照片當配角**：大家拍的照片不一定好看，也不一定配得上 App 的風格，所以動態和食譜頁都用小圖，文字在前。
5. **偶爾用也完整**：不顯示任何頻率、次數、連續天數，也不寫催促的文案。紅點只代表有新通知，不顯示數字。
6. **好讀、好按**：符合 WCAG AA；一隻手拿鍋鏟，另一隻手也按得到。

## 二、色彩

程式裡一律用代碼（token），不直接寫色碼。

| 代碼 | 色碼 | 用在 |
|------|------|------|
| `bg` | `#F4EDE2` | 整個 App 的底（米白）；比白卡深一階，卡片才浮得出來 |
| `surface` | `#FFFFFF` | 卡片、底部分頁列、次要按鈕 |
| `ink` | `#2B2622` | 標題、內文、圖示；燈泡黃上的字 |
| `ink-muted` | `#6E655C` | 說明、時間、輔助文字、沒選取的分頁 |
| `line` | `#E8DFD2` | 標籤、反應、份量按鈕的細邊；卡片與按鈕不用 |
| `line-soft` | `#F1ECE4` | 卡片裡一列一列之間的分隔線；中性標籤的底；頭像的底 |
| `line-strong` | `#D9CBB5` | 動態裡「上次看到這裡」的分隔線；照片「+N」那一格的底 |
| `photo-empty` | `#EFE4D2` | 照片還沒載入時的底 |
| `bulb` | `#F2B705` | 主要按鈕、大廚、「和大廚聊聊」的粗邊、選取中的反應的邊 |
| `bulb-soft` | `#FFF1C2` | 選取中的反應與標籤、對話泡泡、底部分頁列選取中的圖示 |
| `chef-soft` | `#FFF8E1` | 「和大廚聊聊」區塊與大廚點子卡片的底 |
| `tomato` | `#E0533D` | 通知紅點、慶祝的小煙火；只當圖形，不拿來寫字 |
| `green` ／ `green-soft` | `#2F6B3A` ／ `#E3F1E2` | 「廚房有」「食材廚房有」標籤的字／底 |
| `error` | `#B83A2E` | 錯誤與警告；一律搭配圖示與文字，不只靠顏色 |

**對比**（WCAG AA：一般文字至少 4.5:1）

| 文字 ／ 底 | 對比 |
|-----------|------|
| `ink` ／ `bg` | 12.9:1 |
| `ink` ／ `bulb` | 8.2:1 |
| `ink-muted` ／ `bg` | 4.9:1 |
| `ink-muted` ／ `surface` | 5.7:1 |
| `ink-muted` ／ `chef-soft` | 5.4:1 |
| `ink-muted` ／ `line-soft` | 4.9:1 |
| `green` ／ `green-soft` | 5.5:1 |
| `error` ／ `surface` | 5.7:1 |

`tomato` 對白色只有 3.8:1，所以不用來寫字。

**深色模式**：先只做淺色。所有顏色都透過代碼取用，之後加深色模式只要多一組值。

## 三、字型

| 用途 | 字型 |
|------|------|
| 內文、按鈕、說明 | 手機內建的黑體（蘋方、Noto Sans TC、微軟正黑體），不用下載 |
| 大標題、大廚的話、口味名片 | 圓體：jf 粉圓（`jf-openhuninn`），只下載用到的字 |

**字級**（px）

| 字級 | 用在 |
|------|------|
| 28 圓體 | 新手引導、口味名片的大標題 |
| 24 圓體 | 食譜頁的菜名 |
| 22 圓體 | 頁面裡的大標題 |
| 18 | 卡片的菜名、食譜頁的區塊標題（例：「食材」） |
| 16 | 內文、按鈕、輸入框、大廚的招呼語（圓體） |
| 14 | 說明、反應、作者名稱 |
| 13 | 時間、標籤、最小的說明文字 |
| 12 | 只用在底部分頁列的文字 |

- 內文行高 1.6–1.7；標題 1.3。
- 粗體只用一種粗細（700）。
- 輸入框至少 16px，iPhone 點進去才不會自動放大。

## 四、版面

- **寬度**：依手機寬度；在平板與電腦上置中，最寬約 560px。
- **左右邊距**：16px。
- **間距**：同一組裡的東西 8px；一般區塊之間 14px；不同來源的內容之間（大廚的點子和朋友的動態）24px。
- **分頁沒有標題列**：首頁、食譜、廚房、我的都直接從內容開始，上方留出狀態列的安全距離。
- **內頁**：左上角是返回，右上角是「更多」；兩個都是 44×44 的白色圓角方塊，中間不放標題。
- **固定在底部的動作列**：食譜頁的「收藏」「記錄我做的版本」這類動作固定在畫面底部，主要動作在右邊、比較寬。
- **內頁不顯示底部分頁列**：新增、盤點、編輯這類內頁，底部留給固定的動作列，只靠左上角的返回離開。
- **底部分頁列**：白底，五個分頁。中間的「記錄」是 48px 的燈泡黃圓形按鈕，2px `ink` 外框，往上突出一點。選取中的分頁：圖示填 `bulb-soft`、文字 `ink` 粗體；其他用 `ink-muted`。
- **通知在「我的」**：有新通知時，「我的」圖示右上角出現 9px 的 `tomato` 紅點（加 2px 白邊）。通知中心在「我的」裡面。

### 首頁

由上而下：

1. **和大廚聊聊**（見下方元件）。
2. **大廚的點子**：緊貼在大廚區塊下面（8px），一排最多 5 張，可以橫向滑動。
3. **朋友的動態**：和上面隔 24px，一張張白色卡片往下排。

- 畫面上不寫「大廚想到的」「朋友的動態」這類區塊標題。大廚的點子用和大廚區塊同色系的淡黃卡片，朋友的動態用白卡加頭像，看得出是誰給的。
- 程式裡保留看不見的標題（「大廚的建議」「朋友的動態」），讓用報讀器的人可以跳區塊。
- 新舊動態之間有一條細線，寫「上次看到這裡」。
- 滑動中有朋友發了新的食譜，動態最上方浮出一顆「有 2 篇新的」，點一下才載入。

### 我的食譜

- 頂端：「我的食譜｜收藏」分段（44px 高、`line-soft` 底），右邊一顆「更多」（只有「最近刪除」）；沒有檢視切換鈕。下面一個搜尋框（44px、白底），**沒有篩選圓鈕**。
- 「我的食譜」最上方一列「草稿 2 篇 ›」（白底、48px），不混進時間軸。
- 時間軸依月分組：月標題用圓體 18px（「11 月」，非今年的寫「2025 年 12 月」），卡片上不放日期。
- 食譜卡：白底、圓角 10px、內距 10px；左邊 96px 的縮圖（照片不裁切、置中，多張時右下角「3 張」），右邊菜名（圓體 18px）、最多兩行心得（13px `ink-muted`）、最多兩個「值得記住的原因」貼紙。「又做了一次」的日子在菜名上方貼灰色標籤。
- 收藏卡：和食譜卡同樣大小，用來源分辨——朋友的食譜在菜名上方放頭像與「小美 的食譜」，縮圖是照片；大廚的點子放燈泡與「大廚的點子」，左邊是 `bulb-soft` 底的燈泡圖，沒有照片。底下一個標籤：「做過了」（綠）或「還沒做過」（中性）。
- 搜尋結果沿用時間軸的月分組，符合的字用 `bulb-soft` 標出，並註明「名稱符合」或「食材：板豆腐」。
- 草稿匣、最近刪除：白底的列（56px 縮圖），沒有催促文案；草稿左滑露出紅色「刪除」，最近刪除每列「還剩 N 天」加「復原」。
- 空狀態：大廚加一句話，我的食譜另有「記錄一道菜」主要按鈕；收藏只有說明。

### 編輯頁

- 最上面一排照片格（84px，圓角 10px，可左右捲）：第一張左上角貼黑底白字「封面」；右上角 × 的點擊範圍 44px、看得到的圓鈕 24px；最後一格是虛線的「加照片　n / 5」，滿了變淺色不能點；拖曳中的那張微微抬高、轉 3 度、外框 2px `ink`；上傳中蓋半透明深色與進度條，沒傳成功的蓋「重試」。
- 標題與心得放同一張白卡，中間一條 `line-soft` 的線；標題用圓體 24px。
- 「做法」「難易度」在新的一篇是收合的一列（標題＋一行摘要＋右箭頭），打開才展開；已有內容時摘要寫「4 人份・食材 6 樣・3 個步驟」「4 / 10」。
- 步驟最多 10 步，每步一張照片（56px 縮圖，旁邊「換一張」）；沒有照片的步驟顯示虛線的「這步放照片」。滿 10 步時「加一步」變成不能點的「最多 10 步」。
- 難易度是五支 1–5 的拉桿（食材、廚具、時間、技巧、失敗風險），拉桿下方標 1–5，右上角顯示「算出來 4 / 10」。
- 「為什麼值得記住」是固定七個圓角全圓的選項，選中的用 `bulb-soft` 底加 `bulb` 邊。
- 移除照片後，底部浮出深色提示條「移除了 1 張照片　復原」（`bulb` 色的按鈕）。
- 草稿：右上角顯示「已存成草稿」（綠色勾）；已發佈的：顯示黃點「有改過，還沒儲存」，底部的主要按鈕是「儲存」，離開前問「這次改的還沒儲存」。

### 食譜頁

文字在前，照片在後：作者、菜名（旁邊可以貼「第一次做」這類貼紙）、心得、反應列 → 難易度 → 一排照片 → 食材與份量 → 做法。

## 六、元件

### 和大廚聊聊

整個 App 最醒目的區塊，**粗黃邊只用在這裡**。

- 底 `chef-soft`、2px `bulb` 邊、圓角 14px、內距上 48px、左右與下 16px。
- 大廚 56×66px，從區塊上緣探出 30px，靠左 12px。
- 大廚右邊是招呼語「叮！今仔日欲煮啥？」（圓體 16px 粗體）。招呼語固定用這句台語，大廚其他的話用華語（見 [01 語氣準則](01-product-vision.md#語氣準則)）。
- 下方是 44px 高的輸入框：底 `bg`、不用邊框、圓角 10px，提示文字「跟大廚說說心情、手邊有什麼…」。
- 輸入框和區塊底色的對比很低，所以靠提示文字讓人看出這裡可以打字；提示文字的對比符合 AA。

### 大廚的點子卡片（首頁）

- 寬 148px、底 `chef-soft`、圓角 10px、內距 10／12px；不用圖示、不用標題。
- 三行：菜名（16px 粗體）、一句理由（13px `ink-muted`，用大廚的口氣，例：「冰箱的茄子該用了」）、一個標籤。
- 標籤只放一個：主要食材都在廚房裡時放「食材廚房有」（綠），不然放難易度（白底）。
- 一排可以左右滑，停下來時對齊卡片；這一排延伸到螢幕邊緣，最後一張切在邊緣，讓人知道還可以滑。
- 沒有點子時（口味還不夠懂），這一排換成大廚的一句鼓勵。

### 動態卡片

- 白底、圓角 10px、內距 10／12px。
- 第一列：頭像、名字（14px 粗體）、時間（13px `ink-muted`），最右邊是收藏（書籤圖示）。
- 菜名 18px 粗體；心得 14px `ink-muted`，最多兩行。
- 照片：一排最多 3 格，每格 96px 高、間距 4px，只有整排最外側的四個角是圓的。超過 3 張時，第 3 格顯示「+N」（底 `line-strong`）。
- 最下面是反應列。

### 反應列

- 😋（好好吃）一直在第一個。
- 有人按過的其他反應排在後面，依人數多到少；別人可以直接點同一個反應。最多列 5 種。
- 後面是「＋」，打開精選的料理反應（約 24 個，清單見 [02 好友動態](02-features.md#好友動態)）。
- 留言在最右邊：對話泡泡圖示加則數。
- 樣式：32px 高、全圓、1px `line` 邊、14px 字。自己按過的：底 `bulb-soft`、邊 `bulb`。

### 標籤與貼紙

| 種類 | 樣式 | 用在 |
|------|------|------|
| 綠色標籤 | 底 `green-soft`、字 `green`、13px 粗體、圓角 6px | 「廚房有」（食譜頁的每一項食材）、「食材廚房有」（點子卡片） |
| 中性標籤 | 底 `line-soft`（在淡黃卡片上改用白底）、字 `ink-muted` | 難易度、期限 |
| 貼紙 | 白底、1.5px `ink` 虛線框、圓角 4px、微微傾斜 −3° | 值得記住的原因（例：「第一次做」） |

### 按鈕

| 種類 | 樣式 |
|------|------|
| 主要 | 底 `bulb`、字 `ink` 16px 粗體、48px 高、圓角 10px |
| 次要 | 底 `surface`、字 `ink` |
| 文字連結 | `ink` 粗體加底線（例：「列出要買的」） |

一個畫面最多一顆主要按鈕。

### 其他

- **食材清單**：白色卡片，一項一列，列之間用 `line-soft` 分隔；有的食材右邊標「廚房有」。
- **份量**：「2 人份 ▾」，36px 高、全圓、白底細邊。
- **難易度**：五角形雷達圖（`line` 畫格線、`bulb` 畫範圍）加「難易度 3 / 10」與五個面向的分數。

## 七、圖示

- 24px、2px 線寬、圓頭圓角，顏色 `ink`（沒選取的分頁用 `ink-muted`）。
- **最後全部用手繪圖示**。M0 先用現成的圓頭線條圖示佔位，尺寸與名稱照手繪版規劃，之後一次替換。
- 目前用到的：首頁、食譜、記錄、廚房、我的、搜尋、通知、用說的、留言、收藏、返回、加反應、更多。

### 反應圖案

- 先用手機內建的 emoji。
- **之後全部換成手繪的反應圖案**，和 App 的手繪風格一致（線條加平塗），不用作業系統的 emoji。
- 每個反應都用英文代碼存（例：`yummy`），換成手繪圖案時只換圖，資料不用改。
- 手繪圖案在 20px 也要看得清楚；每個圖案都有文字名稱（放語系檔），報讀器唸得出來。

## 八、靈感大廚

- 手繪線條（2.6px `ink`）加平塗：白色廚師帽、`bulb` 燈泡、`ink-muted` 的燈座。
- **只在說話時出現**：對話、點子、新手引導、空畫面、提示。不當裝飾。
- 尺寸：24px（對話泡泡旁）、40px（提示）、56px（首頁的大廚區塊）、96px（新手引導、空畫面）。
- **亮度和顏色就是表情**：

  | 表情 | 什麼時候 | 燈泡顏色 | 嘴形 |
  |------|---------|---------|------|
  | 平常 | 打招呼、說明 | `#F2B705` | 微笑 |
  | 想到點子 | 點子出爐 | `#FFD84D`，亮到最亮 | 張嘴笑 |
  | 思考中 | 等 AI 回覆 | `#F7DFA0`，一明一滅 | 一字嘴 |
  | 安慰 | 料理失敗、說好累 | `#F3C58C` 柔和暖光 | 淺淺的笑 |

### 動畫

用 Rive 做，一個檔案含所有表情與切換（狀態機）。

- **眨眼**：平常每隔幾秒眨一次，間隔不固定，看起來比較自然。
- **廚師帽飄動**：平常輕輕飄；想到點子時彈起來再落下。
- **嘴形與顏色**：換表情時，嘴形和燈泡顏色一起慢慢變過去。
- 手機開了「減少動態」：不眨眼、帽子不動，只保留顏色的淡入淡出。

## 九、動態

- **克制**：日常的轉場 150–250ms、輕微淡入。
- **明顯的動態只有三種**：發佈時的小煙火、大廚的表情、按反應時反應輕輕彈一下。
- 手機開了「減少動態」，全部改成淡入淡出。
- 音效與震動回饋可以關閉。

## 十、照片

- 手機端轉成 WebP 三種尺寸（見 [04](04-architecture.md)）；動態與食譜頁的小圖用 400px，點開看大圖用 1080px。
- 照片不裁切：小圖放在固定大小的格子裡置中顯示（兩側或上下留 `line-soft` 的底）；點一下用全螢幕看原圖。
- 動態和食譜頁都不放滿版的大照片。

---

## 十一、無障礙

- 文字對比至少 4.5:1，大字（24px 以上或 18.5px 粗體以上）至少 3:1。
- 可以按的範圍至少 44×44px。
- 不只靠顏色傳達意思：錯誤有圖示和文字、選取中的反應同時改底色和邊框。
- 鍵盤操作時，焦點用 2px `ink` 外框、往外留 2px。
- 首頁沒有畫在畫面上的區塊標題，程式裡要有看不見的標題。
- 圖示按鈕都要有文字名稱（例：收藏、留言 3 則）。
- 支援「減少動態」設定。

## 十二、之後可以擴充與檢討

| 什麼時候看 | 項目 | 類型 | 怎麼判斷 |
|-----------|------|------|---------|
| M2 後 | 首頁沒有區塊標題，大家分不分得出大廚的點子 | 檢討 | 訪談時問；分不出來就在點子列上方加一行大廚的話「我想到這幾道」 |
| 有人反映晚上太亮 | 深色模式 | 擴充 | 色彩代碼多一組深色的值 |

手繪圖示、手繪的反應圖案、大廚的插圖與動畫是要做的設計工作，列在 [08 待辦事項](08-open-items.md#三待辦事項)。
