# 17 視覺設計

App 的色彩、字型、版面、元件與動態。畫面上的樣子以這份為準；功能與文案見 [02](02-features.md)，大廚的個性與語氣見 [01](01-product-vision.md#大廚角色靈感大廚)。

## 一、設計原則

1. **溫暖家常**：像在朋友家的廚房。米白紙感的底、白色卡片、燈泡黃的重點、手繪的小圖示。
2. **安靜的版面**：卡片和按鈕不用邊框、不用陰影；分頁沒有標題列；首頁不用區塊標題，靠顏色與距離分出區塊。
3. **只有大廚會跳出來**：粗黃邊只用在「和大廚聊聊」。其他地方用淡色與留白，不搶大廚的位置。
4. **使用者的照片當配角**：大家拍的照片不一定好看，也不一定配得上 App 的風格，所以動態和食譜頁都用小圖，文字在前。
5. **偶爾用也完整**：不顯示任何頻率、次數、連續天數，也不寫催促的文案。紅點只代表有新通知，不顯示數字。
6. **好讀、好按**：符合 WCAG AA；一隻手拿鍋鏟，另一隻手也按得到。

## 二、色彩

程式裡一律用代碼（token），不直接寫色碼。

| 代碼 | 色碼 | 用在 |
|------|------|------|
| `bg` | `#F4EDE2` | 整個 App 的底（米白）；比白卡深一階，卡片才浮得出來 |
| `surface` | `#FFFFFF` | 卡片、底部分頁列、次要按鈕 |
| `ink` | `#2B2622` | 標題、內文、圖示；燈泡黃上的字 |
| `ink-muted` | `#6E655C` | 說明、時間、輔助文字、沒選取的分頁 |
| `line` | `#E8DFD2` | 標籤、反應、份量按鈕的細邊；卡片與按鈕不用 |
| `line-soft` | `#F1ECE4` | 卡片裡一列一列之間的分隔線；中性標籤的底；頭像的底 |
| `line-strong` | `#D9CBB5` | 動態裡「上次看到這裡」的分隔線；照片「+N」那一格的底 |
| `photo-empty` | `#EFE4D2` | 照片還沒載入時的底 |
| `bulb` | `#F2B705` | 主要按鈕、大廚、「和大廚聊聊」的粗邊、選取中的反應的邊 |
| `bulb-soft` | `#FFF1C2` | 選取中的反應與標籤、對話泡泡、底部分頁列選取中的分頁 |
| `chef-soft` | `#FFF8E1` | 「和大廚聊聊」區塊與大廚點子卡片的底 |
| `tomato` | `#E0533D` | 通知紅點、慶祝的小煙火；只當圖形，不拿來寫字 |
| `green` ／ `green-soft` | `#2F6B3A` ／ `#E3F1E2` | 「廚房有」「食材廚房有」標籤的字／底 |
| `error` | `#B83A2E` | 錯誤與警告；一律搭配圖示與文字，不只靠顏色 |

**對比**（WCAG AA：一般文字至少 4.5:1）

| 文字 ／ 底 | 對比 |
|-----------|------|
| `ink` ／ `bg` | 12.9:1 |
| `ink` ／ `bulb` | 8.2:1 |
| `ink-muted` ／ `bg` | 4.9:1 |
| `ink-muted` ／ `surface` | 5.7:1 |
| `ink-muted` ／ `chef-soft` | 5.4:1 |
| `ink-muted` ／ `line-soft` | 4.9:1 |
| `green` ／ `green-soft` | 5.5:1 |
| `error` ／ `surface` | 5.7:1 |

`tomato` 對白色只有 3.8:1，所以不用來寫字。

**深色模式**：先只做淺色。所有顏色都透過代碼取用，之後加深色模式只要多一組值。

## 三、字型

| 用途 | 字型 |
|------|------|
| 內文、按鈕、說明 | 手機內建的黑體（蘋方、Noto Sans TC、微軟正黑體），不用下載 |
| 大標題、大廚的話、口味名片 | 圓體：jf 粉圓（`jf-openhuninn`），只下載用到的字 |

**字級**（px）

| 字級 | 用在 |
|------|------|
| 28 圓體 | 新手引導、口味名片的大標題 |
| 24 圓體 | 食譜頁的菜名 |
| 22 圓體 | 頁面裡的大標題 |
| 18 | 卡片的菜名、食譜頁的區塊標題（例：「食材」） |
| 16 | 內文、按鈕、輸入框、大廚的招呼語（圓體） |
| 14 | 說明、反應、作者名稱 |
| 13 | 時間、標籤、最小的說明文字 |
| 12 | 只用在底部分頁列的文字 |

- 內文行高 1.6–1.7；標題 1.3。
- 粗體只用一種粗細（700）。
- 輸入框至少 16px，iPhone 點進去才不會自動放大。

## 四、版面

- **寬度**：依手機寬度；在平板與電腦上置中，最寬約 560px。
- **左右邊距**：16px。
- **間距**：同一組裡的東西 8px；一般區塊之間 14px；不同來源的內容之間（大廚的點子和朋友的動態）24px。
- **分頁沒有標題列**：首頁、食譜、廚房、我的都直接從內容開始，上方留出狀態列的安全距離。
- **內頁**：頂端一列。左邊是返回（44×44、沒有背景色）；標題接在返回後面、靠左，22 圓體、單行，太長就截斷、不換行；右邊一個欄位，可以放按鈕（44×44 的 icon button，同樣沒有背景色），也可以放佔滿剩下寬度的元素（例：「新增食材」的搜尋框）。沒有可見標題的頁，標題只給讀屏軟體。
- **固定在底部的動作列**：食譜頁的「收藏」「記錄我做的版本」這類動作固定在畫面底部，主要動作在右邊、比較寬。
- **內頁不顯示底部分頁列**：新增、盤點、編輯這類內頁，底部留給固定的動作列，只靠左上角的返回離開。
- **底部分頁列**：白底，五個分頁，五格等寬。中間的「記錄」是 48px 的燈泡黃圓形按鈕，2px `ink` 外框，往上突出一點。選取中的分頁：一塊 `bulb-soft` 圓角底同時包住圖示（上）和文字（下），文字 `ink` 粗體；其他分頁的圖示和文字位置相同、沒有底色，用 `ink-muted`，切換時不跳動。
- **通知在「我的」**：有新通知時，「我的」圖示右上角出現 9px 的 `tomato` 紅點（加 2px 白邊）。通知中心在「我的」裡面。

### 首頁

由上而下：

1. **和大廚聊聊**（見下方元件）。
2. **大廚的點子**：緊貼在大廚區塊下面（8px），一排最多 5 張，可以橫向滑動。
3. **朋友的動態**：和上面隔 24px，一張張白色卡片往下排。

- 畫面上不寫「大廚想到的」「朋友的動態」這類區塊標題。大廚的點子用和大廚區塊同色系的淡黃卡片，朋友的動態用白卡加頭像，看得出是誰給的。
- 程式裡保留看不見的標題（「大廚的建議」「朋友的動態」），讓用報讀器的人可以跳區塊。
- 新舊動態之間有一條細線，寫「上次看到這裡」。
- 滑動中有朋友發了新的食譜，動態最上方浮出一顆「有 2 篇新的」，點一下才載入。

### 我的食譜

- 頂端：「我的食譜｜收藏」分段（和廚房的「食材｜廚具」同一個元件：44px 高）；沒有「更多」鈕，也沒有檢視切換鈕；分段照內容寬度、靠右放，左邊留空。下面一個搜尋框（44px、白底），**沒有篩選圓鈕**。
- 「我的食譜」最上方一列「草稿 2 篇 ›」（白底、48px），不混進時間軸。
- 時間軸依月分組：月標題用圓體 18px（「11 月」，非今年的寫「2025 年 12 月」），卡片上不放日期。
- 食譜卡：白底、圓角 10px、內距 10px；左邊 96px 的縮圖（照片不裁切、置中，多張時右下角「3 張」），右邊菜名（圓體 18px）、最多兩行心得（13px `ink-muted`）、最多兩個「值得記住的原因」貼紙。「又做了一次」的日子在菜名上方貼灰色標籤。
- 收藏卡：和食譜卡同樣大小，用來源分辨——朋友的食譜在菜名上方放頭像與「小美 的食譜」，縮圖是照片；大廚的點子放燈泡與「大廚的點子」，左邊是 `bulb-soft` 底的燈泡圖，沒有照片。底下一個標籤：「做過了」（綠）或「還沒做過」（中性）。
- 大廚點子的收藏卡在「做過了／還沒做過」下面放主要食材標籤，規則和首頁卡片相同（廚房有的食材，最多 3 個加「+N」；沒有就放難易度，做過的不放）。點整張卡進完整頁。
- 搜尋結果沿用時間軸的月分組，符合的字用 `bulb-soft` 標出，並註明「名稱符合」或「食材：板豆腐」。
- 草稿匣：白底的列（56px 縮圖），沒有催促文案；草稿左滑露出紅色「刪除」。
- 最近刪除（「我的」頁的一列，進去是內頁）：一頁兩區，「食譜」（含草稿）每列 56px 縮圖、「還剩 N 天」加「復原」；「「廚房名」的食材」每列表情符號、名稱加「復原」。兩區都空時只放一句話。廚具不在這裡，刪除前頁面內確認，文案寫明「刪除後無法復原」。
- 空狀態：大廚加一句話，我的食譜另有「記錄一道菜」主要按鈕；收藏只有說明。

### 我的

- 由上而下：頭像與暱稱、口味地圖與飲食限制（兩列，進內頁）、「平常煮幾人份」「單位」「大廚的語氣」三列、其他（最近刪除、新手引導、帳號、登出）。每列 52px 高，右邊顯示目前的值。
- 人份、單位、語氣三列**各開一個底部抽屜**就地改，沒有設定頁：人份是加減鈕；單位是溫度（攝氏／華氏）和度量（公制／美制）兩組切換；語氣是四個選項，每個附一句例句，點了就選定。改了就存，列上的值馬上更新；存不成功時，錯誤提示顯示在抽屜裡。抽屜底部一顆「好」關閉。

### 編輯頁

- 欄位由上到下：標題與心得 → 照片 → 食材 → 步驟 → 料理筆記 → 為什麼值得記住 → 誰看得到（底部動作列的選單，選項「家人」「好友」「自己」）。編輯頁不放難易度；食材列與步驟左邊是拖拉把手（44px 的點擊範圍、六點圖示；按住把手才拖，不會和捲動打架），右邊是刪除鍵（垃圾桶圖示，44px）；刪掉有照片的步驟時，照片一起移除。已有難易度的舊食譜存檔時原樣保留。
- 照片格（84px，圓角 10px，可左右捲）：第一張左上角貼黑底白字「封面」；右上角 × 的點擊範圍 44px、看得到的圓鈕 24px；最後一格是虛線的「加照片　n / 5」，滿了變淺色不能點；拖曳中的那張微微抬高、轉 3 度、外框 2px `ink`；上傳中蓋半透明深色與進度條，沒傳成功的蓋「重試」。
- 標題與心得放同一張白卡，中間一條 `line-soft` 的線；標題用圓體 24px。
- 「做法」在新的一篇是收合的一列（標題＋一行摘要＋右箭頭），打開才展開；已有內容時摘要寫「4 人份・食材 6 樣・3 個步驟」。
- 步驟最多 10 步，每步一張照片（56px 縮圖，旁邊「換一張」）；沒有照片的步驟顯示虛線的「這步放照片」。滿 10 步時「加一步」變成不能點的「最多 10 步」。
- 「為什麼值得記住」是固定七個圓角全圓的選項，選中的用 `bulb-soft` 底加 `bulb` 邊。
- 移除照片後，底部浮出深色提示條「移除了 1 張照片　復原」（`bulb` 色的按鈕）。
- 草稿：右上角顯示「已存成草稿」（綠色勾）；已發佈的：顯示黃點「有改過，還沒儲存」，底部的主要按鈕是「儲存」，離開前問「這次改的還沒儲存」。

### 食譜頁

頂端一列：左邊返回，右上角兩個 44px 的 icon button：分享、編輯，都沒有背景色、不寫文字（有 `aria-label`）。

文字在前，照片在後：作者、菜名（旁邊可以貼「第一次做」這類貼紙）、心得、反應列 → 難易度 → 一排照片 → 食材與份量 → 做法。

## 六、元件

### 和大廚聊聊

整個 App 最醒目的區塊，**粗黃邊只用在這裡**。

- 底 `chef-soft`、2px `bulb` 邊、圓角 14px、內距上 48px、左右與下 16px。
- 大廚 56×66px，從區塊上緣探出 30px，靠左 12px。
- 大廚右邊是招呼語「叮！今仔日欲煮啥？」（圓體 16px 粗體）。招呼語固定用這句台語，大廚其他的話用華語（見 [01 語氣準則](01-product-vision.md#語氣準則)）。
- 招呼語下面、輸入框上面是一句依時段與大廚的語氣挑的話（圓體 15px），同一天固定一句（見 [01](01-product-vision.md#語氣準則)）。
- 下方是 44px 高的輸入框：底 `bg`、不用邊框、圓角 10px，提示文字「跟大廚說說心情、手邊有什麼…」。
- 輸入框和區塊底色的對比很低，所以靠提示文字讓人看出這裡可以打字；提示文字的對比符合 AA。

### 對話頁

- 點首頁的輸入框或「接著聊」進到全螢幕的對話頁：上方列有返回、標題「和大廚聊聊」、右邊「新對話」。
- **接著聊**：首頁大廚區塊裡、輸入框上方一行白底（`surface`）圓角 10px，大廚的上一句話（一行、超過用刪節號）加右邊 `ink-muted` 的「接著聊 ›」，不放頭像。這時輸入框的提示文字是「想聊點別的？跟大廚說…」。
- 使用者的話：靠右，白底，圓角 14px（右下 4px），系統字 16px。
- 大廚的話：靠左，左邊 24px 的大廚，`chef-soft` 底，圓角 14px（左上 4px），圓體 16px。點子卡片接在下面，往右縮排和泡泡對齊。
- **選項按鈕**：大廚問問題時，最後一則大廚的話下面（往右縮排和泡泡對齊）放 2–4 顆選項：全圓、最少 44px 高、`surface` 底、1px `line` 邊、系統字 15px。單選點了就當作使用者的話送出；多選的先勾（`bulb` 底與邊，`aria-pressed`），旁邊一顆 `bulb` 底的「好了」，沒勾任何一個時是 `line` 底、不能按。多選的上面有一行 `ink-muted` 小字「可以選多個」。使用者隨時可以改用輸入框打字，選項就失效。
- **直接給我點子**：還沒給過點子的每一輪，輸入列上方靠右一顆全圓、44px 高、`bg` 底、1px `line` 邊的按鈕；給過點子之後就不再出現。送出時使用者的話就是「直接給我點子」。
- **點子卡片的「你提到的食材」**：對話裡的點子卡片（白底）在理由下面列出使用者提到的每一樣食材：一行 `ink-muted` 小字「你提到的食材」，下面是一排小標籤；這道有用到的用 `green-soft` 底、`green` 粗體字，沒用到的用 `bg` 底、`ink-muted` 字（螢幕閱讀器另外唸「這道有用到／沒用到」）。使用者還沒提到任何食材時，標籤列照舊放主要食材。
- **思考中**：24px 大廚換「思考中」的表情，燈泡一明一滅，旁邊「大廚想一下…」；整段回應完成才一次出現。等待時不能送出。減少動態時不閃。
- 下方輸入列：白底輸入框（最少 44px 高，可以長高）＋ 44px 的圓形送出鈕（`bulb` 底；沒有字時 `line` 底）。
- **20 輪上限**：大廚說一句，下面一顆 `bulb` 的「開新的一段」，輸入列收起來。只有到 20 輪才這樣；給了點子，輸入列不收、也不出現「開新的一段」。
- **AI 不能用**：大廚換「安靜」的表情說一句；使用者的話照樣留著。

### 點子抽屜

- 首頁與對話的點子卡片點開都是同一個底部抽屜：菜名、一句理由、食材（「你說的」`bulb-soft`、「廚房有」`green-soft` 的小標籤，其他的列在「其他材料」）、做法，最下面一顆「收藏／已收藏」切換（`surface` 底、2px `ink` 外框；已收藏時 `bulb-soft` 底），和卡片右上角的收藏是同一個狀態。
- 做法第一次打開時大廚現寫，不串流，寫好、檢查過才一次顯示：等的時候菜名、理由、食材標籤先顯示，做法區塊放思考中的大廚（`Chef` 的 `thinking`，閃爍）。再開同一個點子直接顯示，不再等。
- 做法顯示：「食材（N 人份）」一行一樣（單位依使用者的偏好），有分組的標組名；「步驟」編號圓點加文字，有計時或目標溫度的在步驟下面用小字（`ink-muted`）；有小提醒的放在 `chef-soft` 的小方塊。顯示做法後，上面的食材標籤與「其他材料」收起來，免得重複；「你說的」「廚房有」的標籤改放在食材清單每一列的右邊（用標準食材 ID 對，沒有 ID 的列不加）。
- 家常菜先顯示骨架：主要食材標籤加「會用到的手法」一行；步驟等大廚寫完再補上。沒有 AI 可問的家常菜（口味還不夠懂、AI 暫停）只顯示骨架與「做法大廚晚點補上」。
- 失敗（逾時、AI 不能用、檢查兩次都不過）：做法區塊換成安靜表情的大廚說「大廚需要再想想」，右邊一顆「再試一次」（全圓、`ink` 邊）；骨架照樣顯示。
- 抽屜裡沒有「不想要」與「做了，記錄一篇」。
- 「食譜 → 收藏」的點子不開抽屜：點卡片進完整頁 `/recipes/saved/:bookmarkId`（見下面〈收藏的點子完整頁〉）。

### 收藏的點子完整頁

- 內頁（沒有分頁列），頂端只有返回（回到「收藏」）。排版像食譜頁：「大廚的點子」小標籤、菜名（24px 粗體）、`chef-soft` 的理由方塊、食材、步驟。
- 做法和點子抽屜同一組：已經展開過的直接顯示；還沒有的，打開時請大廚寫，等待時是思考中的大廚、失敗是「大廚需要再想想」加「再試一次」。食材每一列標「廚房有」（用現在廚房的食材比對）；做法還沒出來時，上面列主要食材。
- 底部固定動作列：左邊「收藏／已收藏」切換（取消後留在頁面，可以再按回來；離開頁面清單才少一張），右邊較寬的 `bulb`「做了，記錄一篇」；記錄過的在上面多一行「打開我記錄的那篇」。

### 大廚的點子卡片（首頁）

- 輪播裡的一張：寬度是螢幕寬減 48px，左右各露出前後一張約 16px 的邊；底 `chef-soft`、圓角 10px、內距 10／12px；不用圖示、不用標題。
- 三行：菜名（16px 粗體，完整顯示不截斷）、一句理由（13px `ink-muted`，用大廚的口氣，例：「冰箱的茄子該用了」）、標籤列。
- 標籤列放主要食材：點子用到的廚房食材與使用者提到的食材，每個一顆綠色標籤，最多 3 個，超過的多一顆「+N」。沒有任何食材時放一顆難易度標籤（白底）。收藏的點子卡片與對話裡的卡片用同一套標籤。
- 一次只看到一張：`scroll-snap-type: x mandatory`、每張 `scroll-snap-stop: always`，一次滑一張。
- 卡片下方一排圓點（6px，目前那張填 `ink`，其他 `line-strong`），只是指示、不能點；只有一張時不顯示。
- 沒有點子時（口味還不夠懂），這一排換成大廚的一句鼓勵。
- 右上角一個收藏圖示（20px 線條，收藏後填 `bulb`；點擊範圍 44px），點一下就收藏或取消，不打開抽屜。
- 對話裡的點子卡片：同樣三行加收藏圖示，改成全寬、直排、白底（`surface`），因為放在 `chef-soft` 的對話旁邊。

### 動態卡片

- 白底、圓角 10px、內距 10／12px。
- 第一列：頭像、名字（14px 粗體）、時間（13px `ink-muted`），最右邊是收藏（書籤圖示）。
- 菜名 18px 粗體；心得 14px `ink-muted`，最多兩行。
- 照片：一排最多 3 格，每格 96px 高、間距 4px，只有整排最外側的四個角是圓的。超過 3 張時，第 3 格顯示「+N」（底 `line-strong`）。
- 最下面是反應列。

### 反應列

- 😋（好好吃）一直在第一個。
- 有人按過的其他反應排在後面，依人數多到少；別人可以直接點同一個反應。最多列 5 種。
- 後面是「＋」，打開精選的料理反應（約 24 個，清單見 [02 好友動態](02-features.md#好友動態)）。
- 留言在最右邊：對話泡泡圖示加則數。
- 樣式：32px 高、全圓、1px `line` 邊、14px 字。自己按過的：底 `bulb-soft`、邊 `bulb`。

### 提示（Toast）

## 七、圖示

- 介面圖示：24px、2px 線寬、圓頭圓角，顏色 `ink`（沒選取的分頁用 `ink-muted`）。食材與廚具的 icon 另有格式，見下一小節。
- **最後全部用手繪圖示**。M0 先用現成的圓頭線條圖示佔位，尺寸與名稱照手繪版規劃，之後一次替換。
- 目前用到的：首頁、食譜、記錄、廚房、我的、搜尋、通知、用說的、留言、收藏、返回、加反應、更多、設定（齒輪，取自 Lucide 的 `settings`，ISC 授權）、已過期與快到期（時鐘，Lucide）、想先用掉（燈泡，Lucide）、分享。
- 存放區：調味（調味罐）、冷藏（冰箱）、冷凍（方冰塊）、常溫（櫥櫃），用在存放區的選單與分組標題；新手引導願景卡的「食譜」（攤開的書）、「廚房」（房子加鍋蓋）。這幾個取代原本的 emoji；口味探索的表情（😋🤩🙂🙅）表達心情，保留 emoji。

### 食材與廚具的 icon

每個食材、廚具都有一個 icon：**墨色線條**，背後疊一層依類別上色的**淡色圓底**。線條和圓底分開存放，線條也能單獨用在別處（`ItemIcon` 的 `plain`）。

**線條格式**（畫圖照這個）
- 24×24 的格子，四邊各留 2 的空白（內容畫在 2～22 之間）。
- `fill="none"`、`stroke="currentColor"`、`stroke-width` 1.75（放進圓底時用 1）、圓角收尾與轉角。SVG 裡不寫死顏色、沒有底色。
- 一個 icon 是一串 path 的 `d` 字串（`string[]`）。以 28px 清單裡認得出來為準：靠外形辨認，細節只用來增加手繪感。

**畫法要點**（`veg.ts` 定下的，其他群組照著畫）
- **一個外形＋2～4 筆內線**。外形是一條封閉的輪廓，佔滿 2～22 的大部分；內線是葉脈、層次、環紋、溝紋、反光這類短線，不畫陰影、不填色、不畫密集紋理。
- 小細節（根鬚、芽眼、刺、粉點）用 1～1.5 長的短線段，不用點：線寬 1 的點在 28px 幾乎看不到。
- 長條形的食材斜放（左下到右上），圓形、球形的置中；梗、蒂頭、葉子放在上方或右上。
- 同類相似的食材，各找一個外形上的差別：例如洋蔥＝頂芽＋根鬚，大蒜＝平頂＋蒜瓣線，紅蔥頭＝兩顆；青椒＝肩凹＋彎梗，甜椒＝方正＋直梗；小黃瓜＝細＋小刺，櫛瓜＝粗＋喇叭形蒂頭。真的分不出來時，寧可共用相近的造型，不要硬加細節。
- 切面能讓食材更好認時畫切面（蓮藕的孔、紫高麗菜的葉層、紫洋蔥的同心環、冬瓜的厚片）。
- 冷凍的食材在左上角加一個雪花（`M5 2.5v5M2.8 3.8l4.4 2.5M2.8 6.3l4.4-2.5`）。
- 檔內依小類分段（蔥薑蒜、葉菜、根莖……），每個 icon 上面一行註解寫它的造型，方便之後調整。

**存放**（`apps/web/src/icons/`）
- 依顏色群組分檔：`veg.ts`、`fruit.ts`、`meat.ts`、`dairy.ts`、`staple.ts`、`seasoning.ts`、`equipment.ts`；每檔 `export const icons: Record<字典 ID, string[]>`。
- 各群組用動態載入，221 個 icon 不會全進主程式；載入前先顯示類別通用 icon。
- 還沒有專屬 icon 的食材、廚具，用**類別通用 icon**（`categories.ts`，食材 21 類、廚具 8 類）。
- 類別與顏色群組的對照放在 `groups.ts`，有單元測試確保字典的每個類別都有對應。

**顏色群組與圓底色票**（`styles.css` 的 `--color-icon-*`；深色模式的低明度版本在 `data-theme="dark"` 之下）

| 群組 | 食材／廚具類別 | 淺色 | 深色 |
|------|----------------|------|------|
| `veg` 綠 | vegetable、mushroom、herb | `#DCEFDC` | `#2E4A33` |
| `fruit` 橘 | fruit | `#FBE3CB` | `#5B3D26` |
| `meat` 磚紅偏棕 | meat、poultry、seafood | `#F0E0D4` | `#543A2F` |
| `dairy` 琥珀 | egg、dairy、tofu-bean | `#FBECC4` | `#5A4A22` |
| `staple` 米色 | grain、noodle、dried-goods、nut-seed、processed、beverage、other | `#ECE3CF` | `#4A4333` |
| `seasoning` 紫灰 | sauce、seasoning、spice、oil | `#E6E0EA` | `#433A50` |
| `equipment` 藍灰 | 廚具的全部類別 | `#DFE7EF` | `#334150` |

**`ItemIcon` 元件**：`kind`（`ingredient`／`equipment`）、字典 ID、`size`。圓底直徑就是 `size`，線條縮到約 60%、線寬 1；線條色用 `ink`（深色模式用淺墨色）。預設當裝飾（`aria-hidden`），需要文字說明時才傳 `label`。清單列用 28～32px（廚具列 40px，和照片縮圖同大）。

**開發用總覽**：開發模式的 `/dev/icons` 依群組列出所有食材與廚具，標出「專屬」或「用類別 icon」，可切淺色／深色；補畫 icon 時用這頁檢查。

## 八、靈感大廚

- 手繪線條（2.6px `ink`）加平塗：白色廚師帽、`bulb` 燈泡、`ink-muted` 的燈座。
- **只在說話時出現**：對話、點子、新手引導、空畫面、提示。不當裝飾。
- 尺寸：24px（對話泡泡旁）、40px（提示）、56px（首頁的大廚區塊）、96px（新手引導、空畫面）。
- **亮度和顏色就是表情**：

  | 表情 | 什麼時候 | 燈泡顏色 | 嘴形 |
  |------|---------|---------|------|
  | 平常 | 打招呼、說明 | `#F2B705` | 微笑 |
  | 想到點子 | 點子出爐 | `#FFD84D`，亮到最亮 | 張嘴笑 |
  | 思考中 | 等 AI 回覆 | `#F7DFA0`，一明一滅 | 一字嘴 |
  | 安慰 | 料理失敗、說好累 | `#F3C58C` 柔和暖光 | 淺淺的笑 |

- 目前的佔位插圖用燈泡顏色、眼睛和嘴形分六種：思考中（`#F7DFA0`、一字嘴；等 AI 回覆時燈泡一明一滅，減少動態時不閃）、平常、開心（眼睛彎彎、張嘴笑）、想到點子（`#FFD84D`、張嘴笑、兩側發光線）、安靜（`#F3C58C`、淺淺的笑；空畫面與沒有點子時用）、驚喜（眼睛睜大、圓嘴；第一篇食譜發佈後）。正式插圖完成後只換 `Chef.tsx`。

### 動畫

用 Rive 做，一個檔案含所有表情與切換（狀態機）。

- **眨眼**：平常每隔幾秒眨一次，間隔不固定，看起來比較自然。
- **廚師帽飄動**：平常輕輕飄；想到點子時彈起來再落下。
- **嘴形與顏色**：換表情時，嘴形和燈泡顏色一起慢慢變過去。
- 手機開了「減少動態」：不眨眼、帽子不動，只保留顏色的淡入淡出。

## 九之一、啟動畫面

## 九、動態

- **克制**：日常的轉場 150–250ms、輕微淡入。
- **明顯的動態只有三種**：發佈時的小煙火、大廚的表情、按反應時反應輕輕彈一下。
- 手機開了「減少動態」，全部改成淡入淡出。

**下層頁轉場**（有「返回」的內頁與對話頁；View Transitions API）
- 進入下層頁（含下層頁再進下層頁）：新頁從右滑入，上一頁往左移約 30%、opacity 降到 0.6。離開：目前這頁往右滑出，上一頁從左 30% 回到原位。約 220ms、ease-out，只用 transform 與 opacity。
- 主要畫面之間（底部分頁、頁內分頁切換）、`replace`、直接開網址的第一次載入不播。減少動態時改成 120ms 的淡入淡出。不支援 View Transitions 的瀏覽器沒有動畫，功能不變。
- 返回後還原原本的捲動位置；進入新頁從頂端開始。
- Safari 瀏覽器（iOS 全部瀏覽器、macOS Safari）的返回手勢與上一頁已有系統動畫，App 不再疊一層：App 自己的返回按鈕（`navigate(-1)`）會先做記號，有記號的返回才播；沒記號的（手勢、瀏覽器上一頁）在這些瀏覽器不播。加到主畫面（standalone）一律播。
- 做法：`TransitionRouter` 取代 `BrowserRouter`，在換畫面那一刻包 `document.startViewTransition`；路由表上標 `handle.inner` 的是下層頁。新增內頁放進 `InnerLayout` 底下即可。
- 音效與震動回饋可以關閉。

---

## 十、照片

- 手機端轉成 WebP 三種尺寸（見 [04](04-architecture.md)）；動態與食譜頁的小圖用 400px，點開看大圖用 1080px。
- 照片不裁切：小圖放在固定大小的格子裡置中顯示（兩側或上下留 `line-soft` 的底）；點一下用全螢幕看原圖。
- 動態和食譜頁都不放滿版的大照片。

---

## 十一、無障礙

- 文字對比至少 4.5:1，大字（24px 以上或 18.5px 粗體以上）至少 3:1。
- 可以按的範圍至少 44×44px。
- 不只靠顏色傳達意思：錯誤有圖示和文字、選取中的反應同時改底色和邊框。
- 鍵盤操作時，焦點用 2px `ink` 外框、往外留 2px。
- 首頁沒有畫在畫面上的區塊標題，程式裡要有看不見的標題。
- 圖示按鈕都要有文字名稱（例：收藏、留言 3 則）。
- 支援「減少動態」設定。
