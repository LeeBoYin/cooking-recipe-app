| 項目 | 目前值 | 出處 |
|------|-------|------|

| 首頁大廚點子的把握程度門檻 | 口味把握程度不夠時不給點子，改顯示鼓勵 | [03](03-ai-design.md)、[13](13-taste-preferences.md) |

| 難易度的計算 | 五個面向相同權重，平均換算成 1–10；偶爾下廚的人平常範圍 1–4；「新挑戰」最多高 1–2 | [03](03-ai-design.md#難易度) |

| 連結期限 | 邀請 14 天、重設密碼 24 小時 | [02](02-features.md#k-帳號與邀請制註冊) |

## 三、待辦事項

### 內容與資料準備（工作量大，可以和開發並行）

| 項目 | 說明 | 何時需要 |
|------|------|---------|
| 食材字典 300 筆 | 別名、分類、家族、是否為生鮮與「最近買的」天數、依地區的當季月份 | M0 |
| 過敏原與飲食限制字典 | 台灣與美國常見的過敏原、飲食限制 | M0 |
| 口味地圖的字典與題庫 | 偏好維度字典（菜系樹、味道、調味系統、口感、料理型態、食材）、80–100 題題庫（描述菜卡、二選一、光譜、快問快答、限制、情境），台灣與美國版本；不用圖片（見 [13](13-taste-preferences.md)） | M0 |
| 宗教與文化的排除規則 | 清真、五辛素、印度教、猶太潔食（部分支援）、初一十五等週期性規則，對應到食材家族 | M0 |
| 口味名片的命名組合 | 「主菜系 × 主要味道」的名稱組合與例外情況 | M0 |
| 快速盤點的常見食材清單 | 約 40 個常見食材的圖示，依地區調整 | M0 |
| 廚具字典的收尾 | 47 個盤點圖示；30 種「看材質」廚具的常見材質預設值 | M0 |
| 手法的技巧等級 | 32 種手法各給 1–5 的 `skillLevel`，作為難易度「技巧」面向的依據（[07](07-equipment-techniques.md#手法的技巧等級)） | M1b（AI 自動估難易度前） |
| 大廚文案模板 | 至少 100 句情境文案（含空畫面、新手引導的願景卡）；邀請訊息範本。全部檢查不含頻率、次數、催促的字眼 | M0 |
| 大廚靜態插圖 | 見第一部分 #2 | M0 |
| 各地區的當季資料 | 台灣與美國的季節分法、當季食材月份、節日料理（決策 18） | M1（推薦用到季節前） |
| 基礎菜色庫 300–500 道 | 台灣家常菜骨架（所需食材、手法、廚具、時間），是點子的候選來源 | M1 |
| 安全資料 | 中心溫度表與台灣資料核對；舒肥預設組合表整理，並請具食品安全背景的人審過 | M1（推薦用到舒肥前） |
| AI 評估集 | 20–30 組假想使用者（含偶爾下廚、記錄很少的新使用者）＋食材狀態，人工標註好的點子 | M1 |
| 隱私說明 | 存了什麼、送給 AI 什麼、管理員看得到什麼、好友看得到什麼、記錄了哪些使用操作（不記內容，可關閉）、怎麼匯出與刪除（決策 24：正式公開時再寫；邀請朋友時先口頭說明） | 正式公開前 |
| 產品事件白名單 | 依 [14](14-product-metrics.md) 的事件清單，在 `shared-types` 定義事件名稱與屬性 | M1a |
| 季訪談的題綱 | 給很久沒打開的人、新加入的人各一份 | M2 |
