# 07 廚具與手法字典

「廚具」模組（見 [02 功能規格 D 節](02-features.md#d-廚具)）和 AI 推薦都以這份字典為準。實作時轉成 `packages/equipment/` 裡的 JSON（格式見文末），隨 App 版本發佈，不需要同步。

**規模**：32 種手法、70 種廚具、20 組替代做法、10 條安全規則，以及每種廚具的清洗標記。

**怎麼判斷「做得到」**：廚房裡有一件對到字典的廚具，它的手法清單（加上使用者確認有的選配功能，例如烤箱的熱風）裡有這個手法，就算做得到。手法由類型決定，使用者不能手動改；自訂的廚具不算。如果這件廚具需要爐火（例如炒鍋），使用者還要有至少一個可用的爐具。都做不到時，查[替代做法](#三替代做法)；替代做法也要符合 `substitutes.json` 的廚具條件（鍋具類同樣要有爐具）。替代做法只用來判斷候選做不做得到；點子寫出的手法與廚具仍然只能是使用者的廚具本身做得到、有的。

## 二、廚具（70 種）

**欄位說明**

- **手法**：這件廚具本身就能做的手法。
- **選配手法**：部分機型才有，使用者登記時可以勾選。例如烤箱有熱風功能，就能近似氣炸。
- **爐**：🔥 表示需要爐具才能用（鍋具類）。
- **盤點**：✓ 表示出現在新手盤點的圖示牆上，★ 表示出現且預設已勾選（大部分台灣家庭都有）。兩者合計 48 種，其中 ★ 有 10 種。★ 是台灣的預設，其他地區另外設定。

### 手法的技巧等級

難易度的「技巧」面向（[03 難易度](03-ai-design.md#難易度)）以每種手法的**技巧等級**（`skillLevel`，1–5）為依據；AI 估難易度時查這張表。標準是「第一次做的人失敗的機率，與需要的手感」：

| 等級 | 意思 |
|------|------|
| 1 | 照做就會，幾乎不會失敗 |
| 2 | 要注意時間或步驟，容錯高 |
| 3 | 需要一點手感或判斷熟度 |
| 4 | 要控溫、控狀態，新手容易失敗 |
| 5 | 靠手感判斷，要練習才穩 |

等級放在 `techniques.json` 的 `skillLevel`（必填）；下表的理由只寫在文件，不進字典，和中心溫度表一樣在程式碼庫維護。

## 四、安全規則

**安全標準（本節的規則、中心溫度表、舒肥預設組合表）只用在 AI 推薦**，不套用在使用者自己或朋友的食譜，也不影響記錄、分享與單位換算。

安全規則由程式檢查，不交給 AI 自行判斷。AI 的推薦用到下列手法時，後端會在顯示前檢查，必要時加上提醒或直接擋下。

| ID | 適用 | 規則 | 檢查方式 |
|----|------|------|---------|
| SR-deep-fry | 炸 | 油量不超過鍋子的一半；食材下鍋前擦乾；起油火時關火、蓋鍋蓋，絕不用水滅火；建議使用溫度計控制油溫 | 固定提醒 |
| SR-sous-vide | 舒肥 | **AI 不得自行產生溫度與時間**，只能從核對過的「舒肥預設組合表」挑選（見下方）；目前只有豬、牛、羊肉有表，禽肉、海鮮、蛋全部擋下；替代做法只用於表中標記為「短時間」的組合；用溫度計確認中心溫度；對孕婦、幼兒、年長者、免疫力較弱者加註提醒 | 程式比對預設組合表（食材、溫度、維持時間、標記），對不上就擋下；展開做法時整篇一起看：至少一步同時帶表裡的溫度、維持時間與標記，沒寫溫度與時間的準備步驟放行 |
| SR-pressure | 壓力烹調 | 依原廠說明書操作；不超過最高水位線；完全洩壓後才開蓋；豆類、燕麥等易起泡食材要注意 | 固定提醒 |
| SR-microwave | 微波 | 不放金屬（含鋁箔、金邊碗盤）；帶殼的蛋不可直接微波；加熱液體可能突沸；密封容器要開孔 | 固定提醒 |
| SR-torch | 炙燒 | 遠離易燃物；只炙燒耐熱容器裡的食材 | 固定提醒 |
| SR-smoke | 煙燻 | 抽油煙機開到最大、保持通風；茶燻時鍋底一定要鋪鋁箔 | 固定提醒 |
| SR-blend-hot | 打碎（熱液體） | 熱的液體不超過容器的一半；蓋子留縫或用毛巾蓋住；從低速開始 | 步驟中有熱湯＋打碎時提醒 |
| SR-cooling | 冷藏定型、剩菜 | 煮好的食物不要在室溫放太久；大量食物分裝成小份再冷藏，冷卻得比較快 | 固定提醒（時間上限待核對） |
| SR-thaw | 冷凍 | 在冷藏室、冷水中或用微波爐解凍，微波解凍後要立刻烹調；不建議放在室溫解凍 | 步驟中有解凍時提醒 |
| SR-doneness | 肉類、海鮮、蛋（所有加熱手法） | 依「中心溫度參考表」（見下方）提醒熟度；有溫度計的使用者，步驟中直接標出目標中心溫度 | 依食材類別帶入 |

### 安全標準依地區

各地區的食品安全標準和飲食習慣不同，所以**安全規則、中心溫度表、舒肥預設組合表都依廚房地區各自一份**，用當地主管機關的標準：

- 台灣用衛福部食藥署的資料，美國用 USDA FSIS；之後加日本時用日本的主管機關（例：日本市售雞蛋以生食為前提管理，生蛋拌飯可以依當地標準處理）。
- 每份表都標註來源，不另外送專人審；參考的人依來源自行判斷查證。新增地區時要整理一份當地的表（見 [15](15-regions-i18n.md)）。
- **還沒有當地表的地區，用現有各份中最嚴格的標準**（每一項取最保守的數值），寧可多提醒。
- 安全規則（上方 SR-*）的提醒文案與觸發條件可以依地區調整，但「AI 不得自行產生溫度與時間、只能從表中挑選」這條全地區相同。

### 日本的中心溫度表

日本沒有按肉類分項的家庭標準；`packages/equipment/safety/JP/doneness-temps.json` 把厚生勞動省「大量調理施設衛生管理マニュアル」的通用標準（加熱調理食品：中心部 75℃ 1 分鐘以上；二枚貝等有諾羅病毒汙染疑慮的食材 85～90℃ 90 秒以上）套用到每一類，取保守值。生蛋與生肉的處理條件目前沒有可直接引用的來源，列為待補。

### 中心溫度參考表

以下數值是美國農業部食品安全檢驗局（USDA FSIS）公布的安全最低中心溫度，作為**美國**的表。**台灣的表依衛福部食藥署等可靠來源另外整理**，兩份都在 App 中標註來源。 攝氏與華氏都存來源上的官方數值，不經換算。

| 食材類別 | 安全最低中心溫度 | 備註 |
|---------|----------------|------|
| 禽肉（全雞、雞胸、雞腿、絞肉） | 73.9°C（165°F） | |
| 絞肉（豬、牛、羊） | 71.1°C（160°F） | |
| 豬、牛、羊的肉排與整塊肉 | 62.8°C（145°F） | 起鍋後靜置至少 3 分鐘 |
| 魚類與海鮮 | 62.8°C（145°F） | |
| 蛋料理 | 71.1°C（160°F） | |
| 剩菜、焗烤料理再加熱 | 73.9°C（165°F） | |

攝氏、華氏都照 2026-11-23 對照的 USDA FSIS 官方頁面原文（`reviewStatus` 為已核對）。

**程式補上的提醒只用該地區官方公布的數值**：有官方華氏值的地區（美國）寫 `{{temp:165:F:min:73.9}}`（兩個單位的官方值都帶），只有攝氏的地區（日本；沒有當地表而取最嚴格的地區，數值多半來自日本）寫 `{{temp:75:C:min}}`。`:min` 表示這是「最低安全溫度」。顯示時依使用者的單位偏好：偏好的單位有官方值就直接用、不換算（美國＋攝氏顯示 73.9°C）；只有另一個單位時才換算，而且**無條件進位**（到整數華氏、半度攝氏），不套一般的進位到 5，所以不會低於官方值（日本 75°C＋偏好華氏顯示 167°F）。一般標記（例 `{{temp:180:C}}`）單位和偏好相同就照原樣、不同才換算並進位到 5；數值可到一位小數。

### 舒肥預設組合表

舒肥能用比一般中心溫度更低的溫度，是因為中心溫度到達後**維持**足夠的時間，也能達到殺菌效果。但安全時間和食材、溫度都有關，**不能讓 AI 自己推算**。這張表由人照可靠的食品安全資料整理，AI 只能從表中挑選。

**表的意思**：肉的**每個部位**中心溫度都到達 X 之後，要再維持 Y（dwell time）。Y 不是泡水的總時間，也不含中心升溫的時間；食材厚度與起始溫度會影響升溫要多久，這由使用者用溫度計確認，表不推算。

| 欄位 | 說明 |
|------|------|
| `category` | 食材類別。目前只有 `meat`：豬、牛、羊的整塊肉（不含禽肉、海鮮、蛋） |
| `tempC`、`tempF` | 中心溫度；°C 與 °F 都存來源列出的數值，不由程式換算 |
| `dwell65Seconds`、`dwell7Seconds` | 維持時間（秒），6.5-log 與 7-log 兩欄 |
| `short` | 短時間組合：只有 `true` 的可以推薦給用「大鍋溫水＋溫度計」替代做法的使用者 |
| `table` | 在來源文件裡的位置 |

厚度上限與最長時間：來源文件沒有，**不填**。維持時間的檢查只有下限（不能少於表上的秒數）。

**用哪一欄**：來源文件第 3 節，烤牛肉、煮熟牛肉、醃牛肉（roast, cooked, corned beef）的標準是 6.5-log，沒有逐項標準的肉（豬、羊等）建議 6.5-log 或 5-log。為了安全，只有「全部是牛肉」的食譜用 6.5-log 欄；豬、羊，或牛肉和其他肉混在一起，一律取比較長的 7-log 欄。

**短時間組合的選法**：140°F（60.0°C）以上、維持時間不超過 12 分鐘（140～157°F，共 18 組）。低於這個溫度的組合要維持十幾分鐘到兩小時，手動控溫很難穩，不推薦給替代做法。

**不列的**：Table 2 的 158～160°F（70.0～71.1°C）維持 0 秒，表示到溫度就達標，那是一般煮到熟、不是舒肥。

**禽肉**：雞（Table 3）、火雞（Table 4）的數值來源文件沒有收，雞、鴨、火雞的舒肥**全部擋下**（見 [08](08-open-items.md)）。魚、海鮮、蛋也不在表裡，一樣擋下。食材混合（豬肉加雞肉）也擋下。

**規則（`rules`，隨舒肥的食譜一起顯示，由程式補上）**：

1. 用溫度計量肉最厚的地方，**每個部位**的中心溫度都到達表上的溫度之後，才開始算維持時間（來源第 35 頁）。
2. 中心溫度從 50°F（10°C）升到 130°F（54.4°C）的時間不超過 6 小時（來源第 24 頁，come-up time）。
3. 做好盡快吃；來源文件沒有煮好之後長時間保存的規則，所以不建議長時間保存，要冷藏照 SR-cooling。
4. 對孕婦、幼兒、年長者、免疫力較弱者加註提醒（SR-sous-vide），建議改用一般煮法、煮到整塊肉的中心溫度（美國 145°F／62.8°C）。

**程式怎麼檢查**：

- **首頁點子、和大廚聊聊、靈感彩蛋**：手法是舒肥的點子，用到的食材要有豬、牛、羊肉，而且不能有禽肉、海鮮、蛋（查食材字典的 traits，字典沒收的說法再用菜名與材料名稱的關鍵字掃）；不合的由程式拿掉。點子不寫溫度與時間。
- **展開做法**：舒肥步驟的 `target_temp_c` 要等於表裡某一組的 `tempC`、`timer_seconds`（到達中心溫度之後的維持時間）不能少於那一組的秒數、步驟文字要帶那一組的溫度標記（`{{temp:140:F:min:60}}`，兩個單位的官方值都帶）；食材同樣要符合上面的條件。不合就整份不用。有舒肥步驟時，小提醒由程式補上上面的規則，並且**不再補**一般的豬牛羊中心溫度（會和舒肥矛盾）。步驟文字照「用溫度計確認肉最厚的地方中心到達 X，再開始計時」寫；水溫設成和目標中心溫度一樣（這是為了讓中心到得了，來源文件沒有另外規定）。
- **替代做法**：只有「大鍋溫水＋溫度計」時（沒有舒肥機、沒有勾低溫模式的萬用鍋），手法清單才開放舒肥，而且只能用 `short: true` 的組合。沒有溫度計就不開放。
- **沒記任何廚具**：不知道有沒有舒肥機，不給舒肥。

> 資料來源：美國的表用 USDA FSIS《Cooking Guideline for Meat and Poultry Products (Revised Appendix A)》2021-12 的 Table 2（第 35 頁），原文摘要放在 `packages/equipment/safety/US/sources/`，單元測試會逐列對照表與摘要。台灣、日本沒有當地表，照「用現有各份中最嚴格的」，也就是用美國這份。這份是業者的 HACCP 指引、不是家庭食安規定，數值只用在 AI 的推薦。

`onboarding` 的值：`"default-on"`（★ 預設勾選）、`"show"`（✓ 出現在盤點）、`"hidden"`（只能從搜尋新增）。`default` 是各地區共用的預設，`byRegion` 依廚房地區覆寫（例：電鍋在台灣預設勾選，烤箱在美國預設勾選，烤魚爐在日本預設勾選；決策 59）。上方表格的 ★ 是台灣的預設。

## 六、維護原則

- **新增廚具**：使用者自訂、但字典沒有的廚具名稱，後台累積統計；同一個名稱被很多人登記，就考慮收進字典。
- **手法由類型決定**：使用者不能替自己的廚具多勾手法；能多勾的只有字典列為「選配手法」的功能（例如烤箱的熱風），資料庫會檢查。
- **安全相關資料**（中心溫度、舒肥組合）每次修改都要留下來源網址，數值照來源原文；PR 審查時對照來源。

## 七、之後可以擴充與檢討

上線後依實際使用再看的事。類型：**擴充**＝之後可以加的功能；**優化**＝讓現有的更好；**檢討**＝回頭確認當初的決定還對不對。全部項目依時間整理在 [08 第四部分](08-open-items.md#四之後可以擴充優化或檢討)。

| 項目 | 類型 | 什麼時候看 | 怎麼判斷 |
|------|------|-----------|---------|
| 技巧等級的校正 | 檢討 | 難易度上線三個月後 | 作者常把某種手法的難度調高或調低時，修正那個手法的等級 |
| 各地區的安全表 | 擴充 | 每加一個地區時（必要） | 依當地主管機關整理中心溫度表與舒肥組合表，標註來源；整理好之前用最嚴格的標準 |
| 「最嚴格標準」的副作用 | 檢討 | 有沒有當地表的地區使用者時 | 最保守的數值是否讓當地常見的做法（例：日本的生蛋拌飯）一直被提醒，造成困擾 |
| 洗碗機標記的用途 | 檢討 | M3 裝備卡上線時 | 清洗負擔拿掉後，洗碗機標記只顯示在廚具卡上；如果沒人看，可以從字典拿掉 |
| 地區特有的廚具 | 擴充 | 每加一個地區時 | 補當地家庭常見的廚具與新手盤點預設（例：日本的烤魚爐） |
